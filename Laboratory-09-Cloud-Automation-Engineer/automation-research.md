# Research: The Language of Automation

## 1. Bash Script

A Bash script is a file containing a series of Linux commands that can run automatically in order to perform specific tasks. The `#!/bin/bash` line, called the shebang, tells the operating system to use the Bash shell to execute the commands in the script.

## 2. Variables

Variables are used to store information, such as folder paths or filenames, so programmers do not need to type the same values repeatedly. For example, `$BACKUP_DIR` stores the location of a backup folder, making the script easier to read, update, and maintain.

## 3. Cron Job

A cron job is a Linux feature that automatically runs commands or scripts at scheduled times and dates. It is essential in cloud operations because it automates repetitive tasks, such as daily backups, reduces human errors, and helps ensure that important maintenance tasks are performed consistently.
