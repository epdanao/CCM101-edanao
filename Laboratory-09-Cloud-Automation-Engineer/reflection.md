# Mission Reflection: Cloud Automation Engineer

Cloud automation helps manage multiple servers by saving time, reducing repetitive work, and minimizing human errors. 
In this mission, I learned how Bash scripts and Cron work together to automate tasks, such as compressing application data and scheduling daily backups at 2:00 AM.
However, automation also requires caution because script errors can affect many servers. 
Testing scripts, checking file paths, setting proper permissions, and maintaining backups help prevent data loss.

Creating a Bash script in Laboratory 9 was different from using Docker Compose YAML in Mission 6. 
Bash executes commands to perform tasks, while Docker Compose defines how containers and services are configured. 
Both simplify system management but serve different purposes.

From Laboratory 1 to Laboratory 9, my understanding of cloud computing grew from basic infrastructure and Linux commands to containers, system
administration, security, and automation. These experiences taught me that managing cloud systems involves not only configuring services but 
also protecting data and ensuring reliability. I enjoyed the Cloud Automation Engineer role the most because I learned how automation makes 
repetitive tasks more efficient. Overall, this mission taught me to automate tasks carefully, test scripts before deployment, and take responsibility 
for the systems I manage.
