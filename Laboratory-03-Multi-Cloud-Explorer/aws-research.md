# AWS Research

## 1. Brief Overview

Amazon Web Services (AWS) is a cloud platform from Amazon that provides organizations with computing and other technology resources over the internet. Instead of maintaining all computing equipment on-site, users can access AWS services when they need them and use them to develop, deploy, and operate applications.

AWS provides services covering many areas of cloud computing, including compute, storage, databases, networking, security, analytics, and artificial intelligence. Its services can be used by organizations of different sizes for a variety of technology requirements.

## 2. Global Infrastructure

AWS operates a global cloud infrastructure organized into **Regions and Availability Zones**. An AWS Region is a geographic location where AWS operates its cloud infrastructure, while Availability Zones are separate infrastructure locations within a Region.

Using multiple Availability Zones can help organizations design applications with greater availability and resilience. When selecting a Region, organizations can consider factors such as the location of their users, network performance, regulatory requirements, and the AWS services available in that Region.

AWS also provides additional infrastructure options, including **Local Zones** and **AWS Wavelength**, for applications that require resources closer to users or devices.

## 3. Cloud Management Console

The **AWS Management Console** is a web-based interface used to access and manage AWS services. Users can use the console to create resources, configure services, monitor their cloud environment, and manage their AWS account.

Through the console, administrators can access different AWS services from one interface and perform tasks such as configuring resources, reviewing usage, managing security settings, and monitoring cloud services.

## 4. Four Core Services

### Amazon EC2

**Amazon Elastic Compute Cloud (EC2)** provides virtual computing capacity through AWS. Organizations can use EC2 instances as virtual servers for running websites, applications, development environments, and other workloads.

### Amazon S3

**Amazon Simple Storage Service (S3)** provides object storage for data. It can be used to store files, application data, backups, images, videos, and other digital content.

### Amazon RDS

**Amazon Relational Database Service (RDS)** is a managed relational database service. It helps organizations operate relational databases while reducing the amount of administrative work required for tasks such as setup, maintenance, and scaling.

### Amazon VPC

**Amazon Virtual Private Cloud (VPC)** allows users to create a logically isolated network environment within AWS. It provides tools for configuring network components such as subnets, IP addresses, routing, and security controls.

## 5. Three Advantages

1. **Flexible scalability** – AWS resources can be increased or decreased according to an organization's changing workload requirements.
2. **Global infrastructure** – AWS operates infrastructure across multiple geographic Regions, allowing organizations to deploy resources closer to their users.
3. **Wide range of services** – AWS provides many cloud services that can support computing, storage, databases, networking, security, analytics, and other technology needs.

## 6. Typical Enterprise Use Cases

Organizations can use AWS for various business and technical workloads, including:

* Website and application hosting
* Virtual server deployment
* Data and file storage
* Database hosting
* Backup and disaster recovery
* Software development and testing
* Enterprise application deployment
* Data analytics
* Artificial intelligence and machine learning
* Cloud migration
* Scalable application infrastructure
