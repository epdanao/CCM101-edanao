# Cloud Platform Comparison

## Comparison of AWS, Microsoft Azure, and Google Cloud Platform

| Category           | AWS                                                       | Microsoft Azure                                                         | Google Cloud Platform                                      |
| ------------------ | --------------------------------------------------------- | ----------------------------------------------------------------------- | ---------------------------------------------------------- |
| Launch Year        | 2006                                                      | 2010                                                                    | 2008                                                       |
| Compute Service    | Amazon EC2                                                | Azure Virtual Machines                                                  | Google Compute Engine                                      |
| Storage Service    | Amazon S3                                                 | Azure Blob Storage                                                      | Google Cloud Storage                                       |

## Analysis Questions

### 1. Which cloud provider offers the broadest range of services?

#### AWS provides a very broad collection of cloud services covering areas such as computing, storage, databases, networking, security, analytics, and artificial intelligence. This variety gives organizations many options when building and expanding their cloud infrastructure.

The large number of available services also makes AWS useful for organizations with different technical requirements, from basic application hosting to more complex enterprise workloads.

### 2. Which provider best integrates with Microsoft technologies?

#### Microsoft Azure is the most natural choice for organizations that already depend heavily on Microsoft technologies. Azure works closely with services and products such as Windows Server, Microsoft 365, and Microsoft Entra ID.

This integration can make it easier for Microsoft-based organizations to extend existing systems into the cloud while maintaining familiar management and identity tools.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

#### Google Cloud is a strong option for workloads involving artificial intelligence, machine learning, and Kubernetes. Google Cloud provides services for developing and managing AI workloads, while **Google Kubernetes Engine (GKE)** provides a managed Kubernetes environment.

These capabilities make Google Cloud suitable for organizations developing cloud-native applications or working with data-intensive and machine-learning projects.

### 4. Which cloud platform would you personally choose and why?

I would personally choose **AWS** because of its broad selection of cloud services and the flexibility it provides. It offers services for computing, storage, networking, databases, security, and application development within the same platform.

As a student learning cloud computing, AWS would also provide opportunities to explore different areas of cloud technology and gain experience with a wide variety of cloud services.

## Cloud Service Equivalents

AWS, Microsoft Azure, and Google Cloud provide comparable services, although each provider uses its own service names and management tools. The following table shows some commonly used equivalents.

| Cloud Service               | AWS        | Microsoft Azure                | Google Cloud                   |
| --------------------------- | ---------- | ------------------------------ | ------------------------------ |
| Compute / Virtual Server    | Amazon EC2 | Azure Virtual Machines         | Compute Engine                 |
| Cloud Object Storage        | Amazon S3  | Azure Blob Storage             | Cloud Storage                  |
| User and Access Management  | AWS IAM    | Microsoft Entra ID             | Cloud IAM                      |
| Managed Relational Database | Amazon RDS | Azure SQL Database             | Cloud SQL                      |
| Managed Kubernetes          | Amazon EKS | Azure Kubernetes Service (AKS) | Google Kubernetes Engine (GKE) |

## Overall Comparison

AWS, Azure, and Google Cloud can all provide the fundamental services required for modern cloud infrastructure. Their main differences are found in their ecosystems, service offerings, management tools, and areas of particular strength.

#### AWS is a strong general-purpose choice with a wide variety of cloud services.
#### Azure is particularly suitable for organizations already using Microsoft technologies.
#### Google Cloud is a strong option for AI, data analytics, and Kubernetes-based workloads.

The best platform ultimately depends on the organization's existing infrastructure, technical requirements, budget, and future plans.
