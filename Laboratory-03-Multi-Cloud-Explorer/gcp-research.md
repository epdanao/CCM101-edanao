# Google Cloud Platform (GCP) Research

## 1. Brief Overview

Google Cloud Platform (GCP), also referred to as Google Cloud, is Google's cloud computing platform. It provides a variety of services that organizations can use for computing, storage, databases, networking, data management, artificial intelligence, and application development.

Instead of depending only on physical servers and infrastructure, businesses and developers can use Google Cloud resources to build, deploy, and manage applications through the cloud.

## 2. Global Infrastructure

Google Cloud operates through a global infrastructure organized into **regions and zones**. These locations allow users to select where their cloud resources will operate based on the requirements of their applications.

Using different geographic locations can help organizations improve application performance, availability, and scalability. Google Cloud's network also provides connectivity across **more than 200 countries and territories**.

When selecting a region or zone, organizations can consider factors such as the location of their users, application performance, data requirements, and regulatory considerations.

## 3. Cloud Management Console

The **Google Cloud Console** is a web-based interface for managing Google Cloud resources and services. It provides users with a centralized location where they can configure and monitor their cloud environment.

Using the console, users can create and manage virtual machines, configure networks, store data, deploy applications, monitor resources, and manage access permissions. It also allows users to organize and manage their cloud projects and services.

## 4. Four Core Services

### Compute Engine

**Compute Engine** is Google's virtual machine service. It allows users to create and run virtual machines on Google's cloud infrastructure. These virtual machines can be configured based on the processing, memory, and other requirements of a workload.

### Cloud Storage

**Cloud Storage** is an object storage service used to store and access data in the cloud. It can be used for documents, images, videos, backups, application files, and other types of digital information.

### Cloud SQL

**Cloud SQL** is a managed relational database service provided by Google Cloud. It allows organizations to run relational databases in the cloud while Google handles many of the underlying infrastructure and maintenance tasks.

### Virtual Private Cloud (VPC)

**Google Cloud VPC** provides networking capabilities for resources running in Google Cloud. It allows administrators to configure networks, subnets, IP addresses, routing, and communication between cloud resources.

## 5. Three Advantages

1. **Strong data and analytics capabilities** – Google Cloud provides services that can help organizations process, analyze, and manage large amounts of data.

2. **Global network infrastructure** – Google's worldwide network allows cloud applications and services to communicate with users and systems across different geographic locations.

3. **Artificial intelligence and machine learning** – Google Cloud provides AI and machine learning technologies that organizations can use to develop, train, and deploy intelligent applications.

## 6. Typical Enterprise Use Cases

Organizations can use Google Cloud for:

* Hosting websites and web applications
* Running virtual machines and cloud workloads
* Storing files, datasets, and backups
* Managing relational databases
* Processing and analyzing large datasets
* Developing artificial intelligence and machine learning applications
* Developing and testing software
* Deploying containerized applications
* Supporting applications used by international customers
* Managing scalable cloud infrastructure
