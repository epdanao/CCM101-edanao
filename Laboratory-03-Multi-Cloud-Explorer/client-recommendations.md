# Cloud Platform Recommendations

## Client A – Startup Company

### Recommended Cloud Platform: Google Cloud Platform (GCP)

Google Cloud Platform is a suitable option for the startup because it provides cloud resources that can be adjusted as the business develops. A startup can begin with the resources it needs and expand its infrastructure when application usage and the number of customers increase.

Using cloud services can also reduce the need for the company to purchase and maintain physical servers. This allows a small technical team to focus more on developing the product while using managed cloud services for infrastructure needs.

### Recommended Services

#### Compute Engine – for running backend servers and application workloads.
#### Cloud Storage – for storing application files, images, and backups.
#### Cloud SQL – for managing relational application databases.
#### Cloud Load Balancing – for distributing traffic across application resources.

## Client B – University

### Recommended Cloud Platform: Microsoft Azure

Microsoft Azure is a suitable platform for a university that already relies on Microsoft technologies. Its cloud services can support existing Windows-based applications while also providing resources for identity management, networking, databases, and other university systems.

Azure can be used to support different types of university workloads, including student information systems, administrative applications, databases, and other services used by faculty, staff, and students.

### Recommended Services

#### Azure Virtual Machines – for running Windows Server applications and other workloads.
#### Microsoft Entra ID – for managing user identities and access to cloud resources.
#### Azure Virtual Network – for creating and controlling the university's cloud network environment.
#### Azure SQL Database – for storing and managing application and institutional data.


## Client C – AI Research Company

### Recommended Cloud Platform: Google Cloud Platform (GCP)

Google Cloud is a strong option for an AI research company because its platform provides computing, data, and artificial intelligence services that can support machine learning workloads. The company can use cloud infrastructure to experiment with models, process datasets, and deploy AI applications without having to build and maintain all computing infrastructure on its own.

The ability to combine computing, storage, containers, and AI services can also help researchers create flexible environments for different experiments and projects.

### Recommended Services

#### Vertex AI** – for developing, training, evaluating, and deploying machine learning models.
#### Compute Engine** – for running customized and resource-intensive computing workloads.
#### Google Kubernetes Engine (GKE)** – for deploying and managing containerized AI applications.
#### Cloud Storage** – for storing datasets, research files, and machine learning resources.


## Client D – Global E-Commerce Company

### Recommended Cloud Platform: Microsoft Azure

Microsoft Azure is a suitable choice for a global e-commerce company because it provides services for computing, networking, databases, application delivery, and scaling. A large online business can use these services to support applications used by customers in different geographic locations.

Azure's scalable infrastructure can also help an e-commerce platform respond to changes in demand. During sales events, holidays, and other high-traffic periods, additional computing resources can be used to support increased application traffic.

### Recommended Services

#### Azure Virtual Machines – for hosting web servers and application workloads.
#### Azure Load Balancer – for distributing network traffic across available resources.
#### Virtual Machine Scale Sets – for managing groups of virtual machines and adjusting capacity according to demand.
#### Azure SQL Database – for managing customer, product, and transaction information.
#### Azure Front Door – for improving the delivery and routing of global web applications.


# Multi-Cloud Decision Matrix

| Business Requirement               | Recommended Platform | Justification                                                                                                                                                                         |
| ---------------------------------- | -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Startup Business                   | GCP                  | Google Cloud provides scalable computing, storage, database, and networking services that allow a startup to begin with a manageable infrastructure and expand as its workload grows. |
| Large Enterprise                   | Azure                | Azure provides a broad range of cloud services for computing, networking, security, identity, databases, and enterprise workloads.                                                    |
| Microsoft-Based Environment        | Azure                | Azure works closely with Microsoft's ecosystem, making it a practical option for organizations that already use Microsoft technologies.                                               |
| Artificial Intelligence / ML       | GCP                  | Google Cloud provides AI and machine learning services such as Vertex AI along with computing and storage resources for AI workloads.                                                 |
| Container and Kubernetes Workloads | GCP                  | Google Kubernetes Engine provides managed Kubernetes capabilities for deploying and managing containerized applications.                                                              |
| International Web Application      | Azure                | Azure provides globally distributed cloud infrastructure together with computing, networking, scaling, and application delivery services that can support international applications. |

# Overall Recommendation

There is no single cloud provider that is automatically the best choice for every organization. The appropriate platform depends on the client's workload, existing technologies, scalability requirements, technical skills, and business objectives.

For the clients evaluated in this mission, **GCP is recommended for the startup and AI research company**, while **Azure is recommended for the university and global e-commerce company**. These recommendations are based on how the available services of each platform align with the requirements of each organization.
