# Mission Reflection

This laboratory activity provided an opportunity for me to develop my practical knowledge and skills in cloud computing by investigating a Linux server through the KillerCoda Playground. It helped me understand the importance of compute, storage, networking, and operating system resources and how these components work together to support cloud-based services. Through the use of Linux commands, I was able to examine the server's CPU, memory, disk capacity, mounted file systems, hostname, IP addresses, operating system, and kernel version. I also gained a better understanding of how Linux supports cloud computing by providing a stable and flexible environment for managing server resources and applications. Researching AWS, Microsoft Azure, and Google Cloud Platform also helped me recognize how different cloud providers offer similar infrastructure services under different names. Creating a simple cloud infrastructure diagram further improved my understanding of how users, internet connections, networks, compute resources, and storage resources are connected. In addition, preparing technical documentation showed me why accurate and organized documentation is important before deploying cloud infrastructure, as it helps engineers plan, communicate, troubleshoot, and maintain systems more effectively. Overall, this laboratory strengthened my Linux, cloud infrastructure, research, documentation, diagramming, and GitHub skills while giving me a better understanding of the responsibilities involved in planning a cloud environment. It also improved my GitHub portfolio by adding organized technical documentation and evidence of practical cloud computing activities.
