# Cloud Provider Comparison

## Comparison of Major Cloud Providers

| Infrastructure Component                 | AWS        | Microsoft Azure                 | Google Cloud Platform |
| ---------------------------------------- | ---------- | ------------------------------- | --------------------- |
| **Compute**                              | Amazon EC2 | Azure Virtual Machines          | Google Compute Engine |
| **Storage**                              | Amazon S3  | Azure Blob Storage              | Google Cloud Storage  |
| **Networking**                           | Amazon VPC | Azure Virtual Network           | Google Cloud VPC      |
| **Identity and Access Management (IAM)** | AWS IAM    | Microsoft Entra ID / Azure RBAC | Google Cloud IAM      |

## Guide Questions

#### 1. Which cloud provider offers the broadest range of services? Explain your answer.

I would consider AWS to have the broadest selection of cloud services. 
It offers many options for areas such as computing, storage, databases, networking, security, analytics, and application development, because of this variety, organizations can choose different services based on the size and requirements of their projects.

#### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I think i would recommend Microsoft Azure because it is designed to work well with Microsoft's existing technologies and services. 
An organization that already uses products such as Windows Server and Microsoft 365 can benefit from Azure's integration with the Microsoft ecosystem, this can make managing users, applications, and existing infrastructure more convenient.

#### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

I would say Google Cloud because Google has a strong background in AI and machine learning and provides cloud services for developing and deploying these types of applications. 
Google is also closely connected with Kubernetes, which originated at Google. Its cloud platform therefore provides a strong environment for organizations that work with AI, ML, and containerized applications.

#### 4. What similarities did you observe among the three cloud providers?

The three providers have almost the same basic infrastructure capabilities even though they use different service names. AWS, Azure, and Google Cloud all provide virtual computing, cloud storage, networking, and identity or access management services. They also allow organizations to provision and scale resources through cloud platforms instead of depending entirely on physical servers.
