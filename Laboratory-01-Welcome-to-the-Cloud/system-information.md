# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduces the fundamentals of cloud computing and provides hands-on experience using a Linux environment. The activity focuses on navigating the Linux terminal, executing basic commands, and documenting system information.

## Objectives

- Understand the basic concepts of cloud computing.
- Become familiar with the Linux command-line interface.
- Execute basic Linux commands.
- Identify system information using terminal commands.
- Create and organize files and directories.
- Document the completed laboratory activities.

## Activities Performed

1. Accessed the KillerCoda Playground.
2. Used the Linux terminal.
3. Executed basic Linux commands.
4. Retrieved system information.
5. Created the required directory structure.
6. Created Markdown documentation files.
7. Created a GitHub repository for the cloud computing portfolio.
8. Uploaded the laboratory documentation and screenshots to GitHub.

## Linux Commands Used

| Command | Purpose |
| `pwd` | Displays the current working directory. |
| `ls` | Lists files and directories. |
| `cd` | Changes the current directory. |
| `mkdir` | Creates a directory. |
| `touch` | Creates a new empty file. |
| `cat` | Displays the contents of a file. |
| `tree` | Displays files and directories in a tree structure. |
| `uname` | Displays system information. |
| `whoami` | Displays the current username. |

## Skills Learned

Through this laboratory activity, I learned how to navigate and work with the Linux command-line interface. I also learned how to create directories and files using terminal commands, collect basic system information, organize documentation, and manage a cloud computing portfolio using GitHub.
