# Security Best Practices

## 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving users only the permissions they need to perform their tasks. It is important in cloud accounts because it helps prevent unauthorized access and reduces the risk of accidental changes or security breaches.

## 2. Attack Surface

The attack surface of a virtual machine refers to all the ports, services, applications, and access points that attackers could potentially target. Reducing unnecessary open ports and disabling unused services helps make the virtual machine more secure.

## 3. Default Deny Policy

A Default Deny Policy means blocking all incoming network traffic unless it is specifically allowed by a firewall rule. It is safer because it prevents unauthorized connections by default instead of trying to identify and block every possible attacker individually.
