# Mission Reflection

Completing this Cloud Security mission helped me understand how firewall configuration and port management work together to protect a server. 
By applying the Default Deny policy and allowing only necessary connections, such as SSH and port 8080, I learned how to reduce unauthorized access. 
I also realized that exposing database ports like MySQL's port 3306 to the public internet can put sensitive information at risk. 
This showed me that even a working application can be vulnerable without proper network security.

These lessons helped me appreciate the importance of checking firewall rules and closing unnecessary ports before exposing a server to a network. 
They also showed me that security requires continuous monitoring and improvement, not just initial configuration. 
As I complete eight cloud computing missions, I am applying these lessons to strengthen my understanding of cloud infrastructure, containers, 
system administration, and security. Documenting my commands, screenshots, and reflections on GitHub also helps me track my progress and demonstrate 
my practical skills.
