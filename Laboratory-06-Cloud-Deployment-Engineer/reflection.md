# Mission Reflection

This laboratory helped me understand how Docker Compose makes cloud deployment easier and more organized. 
Instead of manually typing several Docker commands, I used a `docker-compose.yml` file as a blueprint to configure and run multiple containers with one command. 
I also learned that YAML is sensitive to indentation, and even small spacing mistakes can cause errors. 
Experiencing these errors helped me understand the importance of proper formatting. 
I also learned how environment variables like `MYSQL_PASSWORD`, `MYSQL_DATABASE`, and `MYSQL_USER` provide configuration settings for the containers without putting them directly in the application code. 
Deploying Nextcloud gave me more confidence because I was able to run a real cloud storage application using containers. 
Overall, this laboratory improved my understanding of Linux, containers, storage, virtualization, and cloud deployment. 
It showed me that cloud computing is not only about using cloud services but also about efficiently managing applications and infrastructure.
