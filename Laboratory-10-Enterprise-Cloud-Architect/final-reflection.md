# Final Reflection: Missions 1–10

Throughout Missions 1–10, I learned a lot about cloud computing and how different tools are used to set up and manage a system. Each mission helped me understand topics such as Linux administration, Docker, cloud storage, Infrastructure as Code, system monitoring, and automation. I was also able to apply what I learned by setting up an Ubuntu Server virtual machine in VirtualBox and deploying WordPress and MariaDB using Docker Compose. Other tasks included configuring firewall rules, setting up persistent storage, and creating a Bash script to automatically back up the database using a cron job.

One thing I realized while doing these activities is that making an application work is not enough. We also need to make sure that it is secure, that its data is properly stored, and that it can be recovered if something goes wrong. I also experienced some difficulties with configurations and troubleshooting, but these challenges helped me understand the tasks better. I learned that checking logs, testing the services, and keeping proper documentation are important when managing a system.

Overall, Missions 1–10 were a good learning experience because I was able to practice the lessons instead of just learning them in theory. Through the CloudNova project, I got to combine the different skills and knowledge I gained throughout the activities. It also helped me become more familiar with Linux and Docker and understand the responsibilities involved in maintaining a system. I believe the experience will be useful in future activities and projects related to cloud computing and system administration.
