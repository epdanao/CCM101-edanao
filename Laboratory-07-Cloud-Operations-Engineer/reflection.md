# Mission Reflection

This laboratory activity helped me understand the importance of monitoring in cloud computing. I learned how to check the server's CPU, memory, and disk usage using Linux commands such as `free -h`, `df -h`, and `top`. I also practiced using Docker commands to check container status and application logs.

By sending HTTP requests to the Nginx website, I observed that the homepage returned a 200 status code, while a nonexistent page returned a 404 error. This helped me understand how logs can be used to identify problems. I also learned that logs record events and errors, while metrics show resource usage and system performance. Tools such as Prometheus and Grafana help monitor these details more efficiently.

Overall, this activity improved my troubleshooting skills and taught me to check system information before assuming the cause of a problem. I gained a better understanding of how to monitor containers and maintain application performance.
